# Meine Standortkarte – PWA

## Wichtig
Eine PWA muss über HTTPS oder über einen lokalen Entwicklungsserver geöffnet werden.
Direktes Öffnen der `index.html` aus der Dateien-App installiert die App nicht vollständig.

## Empfohlene Veröffentlichung
Lade den gesamten Inhalt dieses Ordners auf einen statischen Webhoster, zum Beispiel:
- GitHub Pages
- Netlify
- Cloudflare Pages
- eigener Webspace

Danach:
1. Öffne die HTTPS-Adresse in Safari auf dem iPhone.
2. Tippe auf das Teilen-Symbol.
3. Wähle „Zum Home-Bildschirm“.
4. Öffne die App anschließend über das neue Symbol.

## Enthalten
- installierbare PWA
- Offline-App-Shell
- lokale Speicherung der importierten Standortdaten
- TXT-/CSV-Import
- Filter, Routenansicht, Besuchshäufigkeit und geschätzte Aufenthaltszeit

## Datenschutz
Die Standortdaten bleiben im lokalen Browser-Speicher des Geräts.
OpenStreetMap-Kartenkacheln werden aus dem Internet geladen.
